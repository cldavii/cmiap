# Base de documentos de habilitação (FICTÍCIA, apenas para testes)

> Dados inventados para o agente montar o checklist de documentação.
> As validades são fixas de propósito, para o resultado não mudar conforme o dia:
> - a CNDT venceu em 2020, para testar o alerta de documento vencido;
> - os demais vencem em 2099 ou não têm validade;
> - a ISO 27001 e o atestado em aplicativo mobile não existem, para testar documento ausente.

| Documento | Validade |
|---|---|
| Certidão Negativa de Débitos Federais (CND) | 31/12/2099 |
| Certificado de Regularidade do FGTS (CRF) | 31/12/2099 |
| Certidão Negativa de Débitos Trabalhistas (CNDT) | 01/01/2020 |
| Certidão Negativa de Débitos Estaduais | 31/12/2099 |
| Certidão Negativa de Débitos Municipais | 31/12/2099 |
| Certidão Negativa de Falência | 31/12/2099 |
| Balanço patrimonial do último exercício | 31/12/2099 |
| Contrato social e alterações | sem validade |
| Atestado de capacidade técnica: sistema de gestão administrativa | sem validade |
| Atestado de capacidade técnica: portal de serviços online | sem validade |

Documentos que a empresa **não tem**:

- Certificação ISO 27001
- Atestado de capacidade técnica em aplicativo mobile
